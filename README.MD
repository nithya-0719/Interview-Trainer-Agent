Interview Trainer Agent

Overview

Interview Trainer Agent is an AI-powered interview preparation assistant built using IBM watsonx Orchestrate, IBM watsonx.ai, IBM Granite Models, and Retrieval-Augmented Generation (RAG).
The system helps students and job seekers prepare for interviews by providing HR questions, technical questions, role-based questions, and interview preparation tips.

Features

* HR Interview Question Practice
* Technical Interview Question Practice
* Role-Based Interview Preparation
* Interview Tips and Guidance
* RAG-Based Knowledge Retrieval
* AI-Powered Response Generation
* Personalized Interview Assistance

Technologies Used

* IBM watsonx Orchestrate
* IBM watsonx.ai
* IBM Granite Models
* Retrieval-Augmented Generation (RAG)
* GitHub

Dataset

The project uses the following datasets:

* HR_Questions.xlsx
* Technical_Questions.xlsx
* Role_Based_Questions.xlsx
* Interview_Tips.xlsx

## Outcome

The Interview Trainer Agent helps users improve interview skills, build confidence, and prepare effectively for technical and HR interviews through an interactive AI-powered platform.
